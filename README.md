# MemoriNeko（メモリねこ）

macOSのメニューバーに常駐する、猫のアイコンでメモリ使用率を表す小さなアプリ。

数字を読まなくても、猫の表情を見るだけでMacのメモリがどれくらい逼迫しているか分かる、というコンセプト。メモリ使用率が上がるにつれて猫の表情が段階的に変化する。

## 仕組み

- メモリ使用率は5段階（シュッ→普通→ちょいぽちゃ→ぽっちゃり→パンパン）に区切られ、境界付近でのチラつきを防ぐヒステリシス処理を入れている
- 独自のドット絵カット画像（`cat_slim.png`など）があればそれを使い、なければ液面メーター型のアイコンをその場で描画してフォールバックする
- 危険域（75%〜）だけ色がつき、それ以外はテンプレート画像としてライト/ダークモード両対応

## 技術構成

Swift Package Manager製のmacOSメニューバーアプリ（`NSStatusItem`）。外部依存なし。

- `MemoryMonitor.swift` — `host_statistics64`でメモリ使用率を取得
- `CatStage.swift` — メモリ使用率→猫の体型5段階への変換ロジック
- `CatImageRenderer.swift` — Core Graphicsでの液面メーター型アイコン描画（フォールバック用）
- `CatImageLoader.swift` — カスタム画像の読み込み・トリミング・キャッシュ
- `main.swift` — メニューバーへの常駐・タイマー更新・メニュー構築

## ビルド

```bash
swift build
swift run
```

猫のアイコン画像はChatGPTで生成したもの。
