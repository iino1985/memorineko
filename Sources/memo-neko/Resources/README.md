# 猫アイコン画像の配置場所

以下5枚のPNGファイルをこのフォルダに置くと、プログラム生成のドット絵の代わりに使われます。

| ファイル名 | 対応する体型 | メモリ使用率 |
|---|---|---|
| `cat_slim.png` | シュッ | 〜40% |
| `cat_normal.png` | 普通 | 40〜60% |
| `cat_chubby.png` | ちょいぽちゃ | 60〜75% |
| `cat_plump.png` | ぽっちゃり | 75〜90% |
| `cat_stuffed.png` | パンパン | 90%〜 |

- サイズ: 44×44px 推奨（正方形）
- 背景: 透過PNG
- フルカラーOK（isTemplate化はしないのでそのままの色で表示されます）

5枚とも揃っていなくてもOK。見つからない段階の画像はプログラム生成のドット絵にフォールバックします。
